# MOFA GLOW — المتجر الرسمي

متجر إلكتروني بصفحة واحدة لمنتجات العناية بالبشرة، موجّه للسوق المغربي: عربي RTL، الأسعار بالدرهم، الدفع عند الاستلام، يعمل مجاناً على GitHub Pages.

**الرابط الحي:** https://chrvvim.github.io/mofa-glow-store/

> الاختبارات أجريت فعلياً على نسخة محلية مع خادم JSONP تجريبي — تفاصيلها في «تقرير الاختبار» أسفله.

## الملفات
| الملف | الغرض |
|---|---|
| `index.html` | المتجر كاملاً (HTML + CSS + JS، والصور مدمجة base64) |
| `README.md` | هذا الملف |
| `sitemap.xml` | خريطة الموقع لمحركات البحث |
| `robots.txt` | توجيهات الفهرسة (لا يسمح بفهرسة `apps-script/`) |
| `_headers` | ترويسات أمان لـ Cloudflare Pages/Netlify (تُتجاهلها Pages مجاناً) |
| `Code.gs` | قالب Google Apps Script المُحصّن (تُستخدم في Google Sheets، لا تُخدم ضمن Pages) |

## الميزات
- كتالوج بـ 8 منتجات وصورها المضمنة (base64) + بحث + تصنيفات + عرض سريع.
- مفضلة وسلة تُحفظان في متصفح الزائرة (localStorage).
- كود خصم `GLOW2026` (15%)، توصيل مجاني فوق 400 درهم وإلا 35 درهماً.
- نموذج طلب بتحقق من الهاتف المغربي، وقفل لمنع الإرسال المزدوج، وطابور استرداد محلي للطلبات الفاشلة.
- طبقة حركة SAKURA (fly-to-cart، توهج ذهبي، دخول متدرّج، نبضة العداد).
- زر تبديل الوضع الفاتح/الداكن + زر «إتمام الطلب» العائم على الجوال.
- SEO: title، description، Open Graph، canonical، JSON-LD، sitemap.xml، robots.txt.
- حماية XSS + قفل عدم تكرار الطلب + التحقق من الهاتف.

## الإعداد
عدّل `CONFIG` في بداية قسم `<script>` داخل `index.html`:
```js
const CONFIG={whatsapp:"2126XXXXXXXX",sheetUrl:"",sheetToken:"",freeShipAt:400,shipFee:35,promoCode:"GLOW2026",promoPct:15};
```

| المفتاح | الوصف |
|---|---|
| `whatsapp` | رقم المتجر دولي بصيغة `2126XXXXXXXX`. عند ضبطه يظهر زر واتساب عائم ويُنشأ رابط تأكيد للطلب. |
| `sheetUrl` | رابط Web App من Apps Script (`/exec`). عند ضبطه تُسجّل الطلبات في Google Sheets تلقائياً. |
| `sheetToken` | رمز مشترك بين المتجر وApps Script (مضاد للإغراق العشوائي — انظر «ملاحظات أمنية»). |
| `freeShipAt` / `shipFee` | حدود التوصيل المجاني ورسومه. |
| `promoCode` / `promoPct` | كود الخصم وقيمته. |

## ربط Google Sheets (استقبال الطلبات)
1. افتح https://sheets.new ← سمّه `MOFA GLOW — الطلبات`.
2. **Extensions ← Apps Script** ← الصق محتوى `Code.gs` من جذر المستودع.
3. غيّر `SECRET_TOKEN` إلى قيمة عشوائية طويلة (مثلاً `MG7X9q2L8pV4...`).
4. **Deploy ← New deployment ← Web app** ← Execute as **Me** ← Who has access **Anyone** ← Deploy ← انسخ رابط `/exec`.
5. ضع الرابط في `CONFIG.sheetUrl` والتوكن نفسه في `CONFIG.sheetToken`.

### كيف تعمل التركيبة
1. الزبونة تؤكد الطلب ← يُنشأ رقم طلب `MG-<timestamp36>-<random>` فريد.
2. المتصفح يبني طلب JSONP (`<script>/exec?token=...&data=...`) — لا CORS مطلوب لأنه وسم سكريبت.
3. Apps Script يتحقق: التوكن ← الهاتف المغربي ← يعيد حساب الأسعار من `PRODUCT_PRICES` (لا يثق بأسعار المتصفح إطلاقاً) ← يرفض المنتجات غير المعروفة ← يطبع الخصم والتوصيل ← يتأكد من عدم تكرار رقم الطلب ← يكتب في `ORDERS` و`ORDER_ITEMS` ← يسجل في `SYNC_LOG`.
4. يعيد `mgSheetsCallback({ok:true,...})` ← المتصفح يقرأ الجواب ← يعرض شاشة التأكيد **فقط بعد** نجاح التسجيل الفعلي.
5. فشل؟ يبقى الطلب في `localStorage.mg_pending_orders` ويُعاد إرساله تلقائياً عند تحميل الصفحة التالي.

### الأمان داخل Apps Script
- **إعادة حساب الأسعار خادمياً** — أي محاولة لتعديل `basePrice` في المتصفح تُلغى.
- **التحقق من التوكن** — طلب بدون التوكن الصحيح يُرفض ويُسجَّل.
- **التحقق من الهاتف** — `^(0|212)[5-7][0-9]{8}$`.
- **منع التكرار** — نفس رقم الطلب يُرسل مرتين ← `{ok:true,dup:true}` ولا يُكتب صف جديد.
- **سجل مزامنة** — كل محاولة (مقبولة/مرفوضة/استثناء) في `SYNC_LOG`.

### ملاحظات أمنية صادقة
- `sheetToken` في `index.html` مرئي للزوار (موقع عام) — قيمته منع الإغراق العشوائي فقط، **ليس** حماية كاملة ضد مهاجم متعمد.
- Apps Script ليس بديلاً عن خادم backend حقيقي: لا rate-limiting أصيل، ولا WAF. للمستوى الإنتاجي الكامل انتقل لاحقاً إلى Cloudflare Worker (مجاني ضمن حدود) أو Vercel Serverless.
- لا تُخزَّن أي بيانات دفع أو أثمان تكلفة في الموقع العام.
- المنتجات مستحضرات تجميل وليست أدوية.
